# Boss Portfolio Website

## 📌 Project Overview
This project is a **portfolio website** built using **HTML and CSS**.  
It showcases the professional profile of **Mr. John Doe**, including his introduction, experience, skills, projects, a featured YouTube video, and a contact/registration form.

---

## 🛠️ Technologies Used
- **HTML5** for structure
- **CSS3** for styling
- **Responsive design** using `@media` queries

---

## 📂 Project Structure
├── index.html        # Main HTML file
├── index.css         # Stylesheet
└── images.jpg        # Boss image (sample)


---

## 🎨 Features
1. **Introduction Section**  
   - Bio with styled text (bold, italic, underline, highlight, subscript, superscript).

2. **Boss Image with Caption**  
   - Centered image with rounded corners and shadow.  
   - Caption styled in italics.

3. **Experience Section**  
   - Ordered list with alternating font weights (light/bold).

4. **Skills Section**  
   - Styled table with header background, alternating rows, and hover effects.

5. **Projects Section**  
   - Responsive grid layout with project cards.  
   - Cards have shadows, rounded corners, and hover animations.

6. **YouTube Video Section**  
   - Embedded video centered on the page.

7. **Contact / Registration Form**  
   - Clean form design with labels, inputs, radio buttons, dropdown, and submit button.  
   - Styled with focus effects and hover states.

---

## 📱 Responsive Design
- Uses `@media (min-width: 600px)` to switch layouts for larger screens.  
- Example: `.container` changes to **flex layout** with spacing on wider devices.
